# Cluvex Tech

The official Cluvex Tech website: a mobile app development company offering complete solutions from product design through launch and ongoing support.

**Live website:** https://cluvex-tech.github.io/

## Website

- iOS and Android development, Flutter, UI/UX, backend integrations, testing, app store launch, and maintenance.
- Four published games, with category filters, accessible app detail dialogs, store links, and app-specific privacy policies.
- Studio introduction, development process, and email contact.
- Responsive layout, keyboard navigation, reduced-motion support, and progressive enhancement.

The site uses plain HTML, CSS, and JavaScript. No build step or package installation is required. Fonts and artwork are hosted locally.

## Local preview

Run `python3 -m http.server 4173` from this directory, then open http://localhost:4173/.

## Publish

GitHub Pages serves this repository’s `main` branch from the root directory. Commit changes to `main` to publish. `.nojekyll` tells Pages to serve the static files directly.

## Edit

- `index.html`: page content, services, and portfolio cards.
- `styles.css`: visual design and responsive layouts.
- `script.js`: menu, app filters, app details, and email copy interaction.
- `assets/`: original brand assets, official app artwork, and the Manrope font.
- `CONTENT-SOURCES.md`: public reference URLs and content notes.
